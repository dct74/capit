# Capit

一个菜单栏常驻的 macOS 截图标注工具（AppKit 纯程序化，无第三方依赖）。截图后自动加连续圆角 + 原生风格阴影，弹出右下角预览缩略图，点击即可进入标注编辑器；标注结果保存到桌面。也可直接从菜单导入本地图片进行标注。

当前版本：**v1.0.1**

## 功能特性

- **三种截图模式**（菜单栏或全局快捷键）
  - 全屏截图：`⇧⌘3`（也支持 `⇧⌘9`）
  - 区域 / 窗口截图：`⇧⌘4`（也支持 `⇧⌘0`）
- **交互式框选**：区域 / 窗口选择调用 macOS **原生选择界面**（`screencapture -i`）：拖拽框选区域；**空格**在「区域 ↔ 窗口」间切换；**ESC** 取消。原生界面**不激活本 app**，因此不会关闭前台 app 的菜单栏、展开菜单或浮层，行为与系统截图一致；窗口截图天然带圆角/阴影（会被“已处理检测”跳过二次处理）。
- **后处理**：连续圆角 + 原生风格投影，截图时播放系统快门声。
- **右下角预览**：新截图**替换**旧预览（旧图立即落盘），只保留一张；点击进编辑器，超时自动落到桌面。
- **标注编辑器**（菜单「编辑器」或 `⌘E`）：
  - 工具：矩形 / 椭圆 / 箭头（90° 每臂，臂长=杆长 2/5）/ 直线 / 荧光笔 / 文字 / 序号 / 马赛克（纯色填充，默认黑）。
  - 荧光笔用 **Multiply 混合**（压在深色文字上文字依然纯黑）；软过渡宽度是**绝对的 3.5px**，不随笔宽变化——墨往纸纤维里渗是固定距离，不是笔尖的比例——层数因此恒为 18 层。笔迹两端为**平头 + 轻微收虚**（淡出 3px）且宽度全程满宽，既不是尖头也不是圆头；描边连接用 **bevel**，避免圆角连接的圆盘、尖角连接的尖刺在末端堆出多余的一团。笔迹中线叠了一点低频侧向扰动（周期随笔宽自适应、两端淡出），边界不像刀切一样完美。
  - 荧光笔用 **Multiply 混合**，边缘由多层宽度递增、浓度递减的描边叠加出连续的衰减（层数随笔宽自适应：细笔约 12 层、粗笔 18 层，否则层间台阶在粗笔上会摊开成可见的同心带）。笔迹中线叠了一点低频侧向扰动，边界不会像刀切一样完美；末端为平齐收口（停顿不会鼓出圆头）。
  - 支持颜色、线宽、实/虚线、字号；选中即**就地修改**（颜色/宽度/字号/实虚线）；`Cmd+S` 保存，`Cmd+Z`/`⇧Cmd+Z` 撤销重做，`Delete` 删除，**方向键移动选中图形**（`⇧` 加速）；数字自动排序。
  - 打开时默认不选中任何工具；线型/线宽在切换工具或形状时回到默认（实线 / 3，荧光笔 16）。
  - 荧光笔的光标本身就是一把尺子：光标高度**等于笔划粗细**，上下两条横杠就是笔迹的上下边缘，所以在调线宽时可以直接照光标预估成品粗细。
- **导入本地图片标注**（菜单「编辑器」）：支持 **png / jpg**，自动套用圆角 + 阴影后进入编辑器；保存时 **PNG 源覆盖原文件**，**JPG/JPEG 源转为同目录同名的 PNG**。
  - **已带圆角/阴影的图片不再重复处理**：Capit 自己导出的 PNG（内嵌标记）或 macOS 原生窗口截图（alpha/几何启发式判定）会原样打开，跳过二次圆角与阴影。
  - 关闭编辑器但未保存时**不会改写源文件**。
- **关于**：菜单「关于」显示当前版本。
- **自动退出（可选）**：默认不自动退出。可在菜单勾选「空闲 10 分钟后自动退出」，连续 10 分钟无截图/标注操作后自动退出（可用环境变量 `CAPIT_IDLE_SECONDS` 覆盖秒数，便于测试）。

## 运行环境

- macOS 13.0+
- Apple Silicon（arm64）
- 需要**屏幕录制**权限（截图功能）

## 构建与打包

本机约定：所有仓库统一放在 `~/Documents/projects/` 下，本项目路径为 `~/Documents/projects/capit`。

```bash
# 1) 克隆（若尚未克隆）
cd ~/Documents/projects
git clone git@github.com:dct74/capit.git
cd capit

# 2) 仅编译可执行文件
swift build -c release

# 3) 打 .app（ad-hoc 签名，写入 build/Capit.app）
./make_app.sh release

# 4) 启动
open build/Capit.app
```

产物 `build/Capit.app` 完全自包含（单可执行文件 + 图标 + Info.plist），无外部框架，可直接拷贝到别的 Mac。

## 更新日志

### v1.0.1
- **荧光笔边缘重做为连续渐变。** v1.0 的边缘是"湿边 + 笔芯"两遍描边，会在边缘留下一条可见的台阶，而且墨色只有 0.5 浓度上限。
  - 软过渡宽度改为**绝对的 3.5px**（原为半宽的 43%）：墨往纸纤维里渗是固定距离，所以 240px 宽的笔尖不该有 30px 的软边。层数因此**恒为 18 层**，不再随笔宽爬到 40 层，全幅重绘也随之变快。
  - 两端改为**平头 + 轻微收虚**（淡出 3px）：把承载浓度的内层按浓度截短、让最宽最淡的几层贯通到底，所以末端像上下两边一样淡淡收虚，**而宽度全程满宽**——既不是尖头，也不是圆头。
  - 描边连接改用 **bevel**：圆角连接会在每个顶点填一个半径等于半宽的圆盘，尖角连接会甩出半个笔宽的尖刺，两者都会在末端堆出多余的一团。
- **修掉笔迹末端偶发的一团墨**（停留时间稍长、或采样节奏刚好时出现）。根因是**平头端帽被转过角度**——端帽垂直于它所在的线段，线段一旦被转过角度，端帽就会沿笔迹方向戳出半个笔宽。同时修掉两个诱因：侧向扰动的周期短于采样间距而被混叠成逐点抖动；重采样可能留下极短的末段，而短线段上的微小侧移等于大角度。
- **修掉纸纹的横向拉丝**：`draw(image, in:, byTiling:)` 会先把图像缩放到填满矩形再平铺，因此按笔迹包围盒平铺时纸纹被沿笔迹方向拉伸约 4.5 倍（实测自相关比 1.49–4.35）。改为按原始像素尺寸手工铺贴后恢复各向同性（1.00）。
- **修掉颗粒浓度补偿失效**：颗粒只减墨，原来把浓度旋钮顶在饱和点，中心浓度无论怎么调都停在 0.78。
- **荧光笔光标改成"尺子"**：光标高度精确等于笔划粗细，上下两条横杠就是笔迹的上下边缘，调线宽时可直接照光标预估成品粗细。

### v1.0
首个正式版。v0.9 只改过版本号、未单独发布，其改动并入本版。

- **荧光笔重做为真实马克笔效果**：
  - 改用 **Multiply 混合**（原为半透明叠加），墨色因此可以加到 0.85 浓度：压在深色文字上时文字依旧纯黑清晰，浅色纸面正常着色；半透明叠加做到这个浓度会把文字整段洗掉。
  - 分层绘制：**湿边**（更宽更淡的外缘）+ **笔芯**，两层都 Multiply 叠加，所以笔迹中间比边缘浓；笔芯再叠一层确定性生成的**纸纹颗粒**，做出渗墨的不均匀密度。
  - 默认改为**自由笔迹**：采样点用 Catmull-Rom 曲线渲染并做指数低通，不再有折线锯齿；**按住 `⇧` 拉成水平直线条**（原行为）。

### v0.8
- **自动退出改为可选项**：菜单新增「空闲 10 分钟后自动退出」勾选项，**默认不自动退出**，选择会持久化保存。
- **内存优化**（输出像素完全不变）：
  - 右下角预览只保留缩略图，全尺寸 PNG 编码一次后直接移动到桌面，去掉到期时的重复编码；
  - 编辑器保存改为零拷贝生成 `CGImage`，不再复制整张图；
  - 显著降低截图/标注过程的瞬时内存峰值与 CPU 占用。
- 文档：更新自动退出说明。

### v0.7
- 导入本地图片标注：PNG 源覆盖原文件，JPG/JPEG 源转为同目录同名的 PNG。
- 已带圆角/阴影的图片（Capit 自身输出或原生窗口截图）不再二次处理。
- 标注工具统一使用十字光标。
